The 8 Core Coding Patterns to Master

1. Sliding Window: Substrings, subarrays with target sum/length. (O(N) time, O(1) space).
2. Two Pointers: Sorted array pair sums, palindrome checking, in-place swaps.
3. Fast & Slow Pointers: Cycle detection in linked lists, finding midpoint.
4. Merge Intervals: Meeting rooms, calendar conflicts, overlapping time ranges.
5. Top K Elements (Heap): Using Min-Heap of size K for largest elements in O(N log K).
6. Monotonic Stack: Next Greater Element, Daily Temperatures, Stock span.
7. BFS / Level-Order: Shortest path in unweighted graphs, tree depth traversal.
8. Dynamic Programming: Knapsack, Coin Change, Longest Common Subsequence.

Top 6 Must-Memorize CS Fundamental Facts

  • ACID vs BASE: Relational databases enforce Atomicity, Consistency, Isolation, Durability. NoSQL databases use Basically Available, Soft state, Eventual consistency.
  • Process vs Thread: Processes have separate virtual memory address spaces (heavyweight); threads share memory and file descriptors within the same process (lightweight).
  • Indexing: Clustered index sorts physical data on disk (only 1 per table); Non-clustered index stores pointers to rows (multiple allowed).
  • TCP 3-Way Handshake: SYN -> SYN-ACK -> ACK. Termination: FIN -> ACK -> FIN -> ACK.
  • OOP 4 Pillars: Encapsulation (data hiding), Abstraction (hiding implementation), Inheritance (code reuse), Polymorphism (overloading & overriding).
  • HTTP Status Codes: 200 (OK), 201 (Created), 400 (Bad Request), 401 (Unauthorized), 403 (Forbidden), 404 (Not Found), 500 (Server Error).

60-Second "Tell Me About Yourself" Formula

Structure your answer into Present (20s) + Past (25s) + Future (15s):

"I am a final-year CS graduate passionate about full-stack engineering and cloud microservices (Present). Recently, I built a scalable web application using Python and React that reduced data processing latency by 30% for 500 active users (Past). I've been following your company's high-impact distributed systems work, and I'm eager to contribute my problem-solving skills to your engineering team (Future)."
